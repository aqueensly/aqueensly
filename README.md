## Featured project: Learn with Q

**[Explore the live platform →](https://learn.queensly.me/)**

Learn with Q is a free AI education platform I created to help people build a rigorous understanding of how AI works, from fundamentals to the broader ecosystem.

The learning experience brings together:

- **Illustrated video lessons and structured readings** that explain concepts step by step.
- **Practice and self-checks** with feedback that helps learners revisit difficult material.
- **Captions, transcripts, and saved progress** so learners can study at their own pace.
- **An AI-assisted production workflow** connecting research, lesson writing, voiceovers, animation, review, and publishing.

I built the platform through AI-assisted development, without a traditional software engineering background. That experience has made me especially interested in tools that widen access to building and learning.

**The course is public; the application source code and internal production materials are intentionally private.**
